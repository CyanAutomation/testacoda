About the metrics

Languages and published releases come from GitHub. Source lines count non-empty lines in recognised code files, excluding dependency, build and vendor directories; comments are included. Large repositories are sampled up to 25 files and 1 MB, and marked partial. Test declarations are a source-based estimate of JavaScript/TypeScript test(), it(), Python test_ functions and Go Test functions, not executed or passed tests. Dynamically generated cases and other test frameworks are not counted. File counts are shown separately. Public GitHub API rate limits apply. Repository screenshots may represent an earlier version. Diagrams show project structure rather than a live app.
